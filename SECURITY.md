# Security Policy

## Supported Versions

We actively support and provide security patches for the following versions of SwiftBlock:

| Version | Supported          |
| ------- | ------------------ |
| 1.x.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Vulnerability

The SwiftBlock team takes security vulnerabilities seriously. If you discover a security vulnerability in SwiftBlock, please follow these guidelines:

### How to Report

1. **Do NOT report security issues via public GitHub issues, discussions, or pull requests.**
2. Report the vulnerability privately via **GitHub Security Advisories**:
   - Navigate to the **Security** tab of this repository on GitHub.
   - Click **Report a vulnerability** to submit a private draft advisory.
3. If GitHub Advisories are unavailable, contact maintainers directly via email or repository owner profile.

### Information to Include

Please provide as much information as possible to help us reproduce and resolve the issue quickly:
- Description of the vulnerability and its potential impact
- Detailed steps to reproduce the issue (including sample CLI commands or brick definitions)
- Any potential remediations or patches if you have developed one

### Response Timeline

- **Initial Acknowledgement**: Within 48 hours of receipt.
- **Assessment & Fix**: We will triage the severity and provide regular progress updates while developing a fix.
- **Public Disclosure**: Once a patch is released (via hotfix or minor release), an advisory will be published with credit to the reporter (unless anonymity is requested).
